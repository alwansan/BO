# بروتوكول الجلسة
1. افتح RESTORE واتبع AGENTS؛ اقرأ HEAD الحي والنتائج الحية.
2. اختر gate واحداً أو مجموعة مستقلة؛ سجل نقطة البداية وSHA والدليل.
3. اختبر fail-closed؛ لا تغيّر تعريف النجاح لتجاوز الفشل. افصل synthetic/static/build/device.
4. سجل الكود المختبر وRun ID والنتائج والقيود. لا تنقل secrets أو أصول اللعبة إلى السجلات. 
5. حدث STATE/MEMORY/PLAN/ISSUES والجلسة ورسالة RESTORE، ثم commit وتحقق من HEAD. عند نتيجة CI لاحقة حدّث ثانية في الجلسة التالية. أي تدخل من المالك يوثق صراحة.
