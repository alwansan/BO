# Work55 — استمرار شاهد المشهد بعد انتهاء مهلة فتح الملفات

- اجتاز المشهد الأصلي الفحوص الستة في المختبر، وبعدها أطلق P1 ثلاث طلقات أصابت الجزء المؤلف المطابق دون نفاده. في القياس المتأخر تغيّرت القراءة إلى `1 0 1 1 0 0`: بقيت الحلقة والتدفق وثبات اللاعب، لكن مهلة 15 ثانية منذ آخر فتح مورد مؤهل أغلقت الشاهد النهائي رغم استمرار اللعبة. سجل المختبر 5280 إطارًا بلا إشارة.
- صار شرط حديثية الملفين خاصًا بالتأهيل الأول. بعده يستمر استخدام دليل **جيل الزوج نفسه** فقط ما دام مشهد اللعبة السابق مثبتًا والهوية والخيط والطور الحاليون متطابقين. تغير الحلقة أو إعادة تكوين زوج الملفات يبطل الدليل القديم؛ وفقدان المشهد لا يسمح باستعادته بزوج منتهي. بقيت مهلة تقرير فتح الملفات الأول كما هي.
- نجح اختبار ملفي المشهد مع ASan/UBSan، وستة اختبارات تجهيز المصدر وتجميع وحدات Android السبع. إعادة محرك المختبر بالإصلاح تقيس استمرار المطابقة بعد المهلة. لم يثبت نفاد الجزء بطلقة P1 إلى بوابة الناشر أو JNI الحي أو APK قبول.
