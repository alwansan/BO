# Work46 — تنفيذ خاص لجزء دورة عمر الوحدة على Android

نجح [فحص وحدات Android 45910176234](https://github.com/alwansan/BO/actions/runs/45910176234) و[فحص تحويل المصدر 45910176273](https://github.com/alwansan/BO/actions/runs/45910176273) على `7acb0901f6c084013dc72f810e5188a6b3af3e9c`. سجل الأول النجاح لكل وحدات ARM64 السبع، ومنها `src/game/cheats.cpp` حيث دخلت الخطافات.

## دليل التنفيذ الخاص

نفذ اختبار C++ غير منشور على Android API 35 بملف ARM64 يحمّله `/system/bin/linker64` ومع ASan/UBSan. استخرج الاختبار لفافات الفصل والنشر والربط الثلاث كما جهزها المصدر، وربطها بأجسامها المولّدة بالـSDK المثبت للصورة الأصلية المطابقة. نفذت دوال قائمة العالم الأصلية `001BEB40` و`001CE1F0` دون استبدال، ونفذ فرع النشر المتأخر من `001EB7F0` باستخدام جدول قفز الصورة نفسها. تغيرت القائمة داخل الدوال الأصلية، وتحقق الاختبار من مكدس كل استدعاء ومن إزالة كل أعضاء المجال قبل إعادة نشر الوحدة وربطها في تخصيص عالم آخر. صدرت العلامتان بهذا الترتيب فقط:

```text
BO_ANDROID_PRIVATE_SLICE_EVENT 2132
BO_ANDROID_PRIVATE_SLICE_EVENT 2133
BO_ANDROID_PRIVATE_ORIGINAL_UNIT_SLICE_PASS
BO_ANDROID_PRIVATE_SLICE_EVENT_ORDER_VERIFIED
```

## حدود النتيجة

ذاكرة الوحدة والمشهد والمكدس اصطناعية. استُعيض عن التوابع غير اللازمة للقائمة، وشغّل الاختبار فحص الإطار بعد نقل قيم المرحلة بدل تشغيل التحديث الكامل `001F1080`. العلامات من مستقبل الاختبار وليست من Java أو سجل APK؛ لا اختبار تحميل مرحلة كاملة أو إعادة مهمة من القائمة في تطبيق Android. لم تُرفع ملفات تنفيذية أو صورة أو شيفرة توليد. [الملخص المسموح](../evidence/WORK_BATCH46_ANDROID_UNIT_LIFECYCLE_SLICE.json).

لم تُفعّل المزامنة ولم يُصدر APK قبول. التالي تنفيذ الاختبار الخاص عبر التطبيق والمحرك الكاملين، والتحقق من تصدير العلامتين بعد إعادة المهمة ومن انتقال حالة عنصر/هدف أصلي مستقل.
