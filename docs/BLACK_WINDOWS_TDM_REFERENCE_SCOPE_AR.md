# BLACK-Coop — حدود الاستفادة من BLACK-XBEMultiplayer (نوفمبر 2026)

المصدر الذي أرسله مالك المشروع: https://github.com/Peterson047/BLACK-XBEMultiplayer

قرأت README مباشرة. المشروع نسخة Windows Alpha للعب **Team Deathmatch**، حتى ثمانية لاعبين، باستضافة LAN/عنوان مباشر، ومُشتقة من تنفيذ إعادة تجميع اللعبة لأجهزة PC. يعرض تشارك حركة ومواضع اللاعبين، الأسلحة والقتل ومؤثرات خطوات الأقدام، لكنه **ليس طور قصة BLACK الأصلي بشخصيات بشرية تتشارك أحداثها ومهامها**.

هذا المستودع يقدّم BLACK.exe وملفات تشغيل/إعدادات وموارد عرض قليلة، وينص README صراحةً أنه **binary-only** بلا مصدر المحرك. يشير README إلى مشروع المصدر `Peterson047/BLACK-Coop` وفرع `feat/windows-multiplayer` وCommit `095488c`، لكن محاولة الوصول إلى ذلك المستودع أعادت 404 في جلسة 69. لذلك لا يجوز الإبلاغ عن نسخ كود اللاعبين منه ولا اتخاذ دواله غير المتاحة دليلاً مثبتاً.

**الاستفادة الصحيحة:** الاستفادة من منهج فصل خيوط الشبكة والرسم، رموز اللاعبين المستقلة، المؤثرات التزامنية، والمبدأ الخادم الموثوق؛ ومن المشروع المفتوح `portingpete/Black-2006-Recomp@b2512fafd` لفهم مظهر بوت حقيقي (من دون نقل AI)، مع التحقق المستقل من ABI على XBE الأصلية المملوكة للمستخدم. لا ننسخ ملفات exe أو محتويات اللعبة ولا ننقل أي نموذج/صوت غير مرخص.

الهدف الحالي: قصة المضيف الحقيقية، الضيف يشغل نفس المرحلة تلقائياً، مشهد محمل مثبت، وظهور أجسام اللاعبين 2–4 من أي مظهر بوت أصلي. **TDM لا يعوض القصة.**
