# BLACK Co-op — الجلسة 74: اختبار جماعي لثلاثة ضيوف مع المضيف

هذا الاختبار يستخدم **أربع اتصالات TLS حقيقية** في GitHub Actions: مضيف وثلاثة ضيوف. تُحاكى فقط إشارات محرك BLACK الأصلي على خيط الاختبار لأن GitHub JVM لا يشغل اللعبة ثلاثية الأبعاد. لا يجوز وصفه باختبار تعاوني قابل للعب.

الاختبار يتأكد من وصول تذكرة المرحلة إلى الأربعة، وأن جاهزية ضيفين لا تبدأ الجلسة قبل جاهزية الضيف الثالث؛ وعندما يكتمل الحاجز تنشر جهة المضيف أربع مواقع (الموقع الأصلي لللاعب الأول، وثلاثة مواقع قيمة افتراضية يتحكم فيها المضيف من خلال حركات صادرة من الاتصالات الموثقة). يستلم كل ضيف الحالة ويعيد ترميزها وفق خانته المختصرة 2 أو 3 أو 4. عند خروج الرابع تُلغى التذكرة وتُمسح بيانات المواقع والحركات القديمة؛ وبعد إعادة دخوله برقم TLS أعلى يعاد تعيينه إلى خانته المختصرة 4 وتُنشأ تذكرة مشهد جديدة.

يبقى المطلوب قبل تجربة الهاتف الكبيرة: إطلاق مستوى المضيف تلقائياً على أجهزة الضيوف من داخل واجهة اللعبة الأصلية، ثم مجسم بشري مرئي لكل ضيف (أي Bot أصلي مقبول)، وأخيراً مزامنة فعلية للعدو والطلقات والأهداف في **العالم نفسه** تحت سلطة المضيف.
