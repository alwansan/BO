# BO-COOP — Direct IPv4 + pinned TLS join and platform test gate
Latest dated 2026-11-21, session30.

**Working in code:** `RoomDirect.parse("192.168.1.9:1508")` accepts only explicit canonical decimal IPv4 and unprivileged TCP port. Rejects DNS/hostnames, broadcast/multicast, octal-looking leading zeroes, padding and invalid ranges. `RoomDirect.fingerprint()` accepts exactly 32 SHA256 bytes encoded as 64 hex characters or 32 hex pairs with colons, and rejects truncated/Unicode lookalike pins. `RoomDirect.join()` calls the **real** `RoomTls.pinnedContext(fullPin)` and `RoomTls.Client.connect`. No trust-all TLS, private key export, network-thread guest writes or assets. Synthetic real-socket JVM regression [44920763536](https://github.com/alwansan/BO/actions/runs/44920763536) PASS, source8df7a683.

**Platform challenge:** Android 29 emulator boot and synthetic package installed; actual TLS handshake failed with RSA-only AndroidKeyStore alias. Diagnostic run [44921892101](https://github.com/alwansan/BO/actions/runs/44921892101) showed Conscrypt requested `EC`, server handshake exception before JOIN. Updated `RoomIdentity` to generate **EC P-256**, separate alias and EC X509KeyManager; retry [44922289967](https://github.com/alwansan/BO/actions/runs/44922289967) pending until verified. `KeyProperties.DIGEST_NONE` is configured for prehashed TLS signatures per official Android KeyGenParameterSpec documentation. No credentials or certificate keys in repo/artifacts.

**Incomplete:** No APK game integration, Host/Join Android forms, QR out-of-band pin transfer, actual 2-phone LAN verification, body/actor spawn or mission sync. The user's accepted UI-only APK still shows HOST/JOIN unavailable. Next bridge must post immutable status to Flash from a bounded worker thread. The host is a real person on the phone; NPCs are not counted as peers.
