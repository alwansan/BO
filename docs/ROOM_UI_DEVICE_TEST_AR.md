# اختبار قائمة CO-OP الجديدة

هذه نسخة واجهة تجريبية باسم **BLACK Co-op UI TEST**، وحزمتها `org.bocoop.black.roomui`. بناء Actions 44913654405 نجح، وتم تنزيل APK وفحص بصمته مستقلاً. تستخدم ISO الحالية؛ لا تحتاج ISO جديدة، ولا تختبر هاتفين لهذه النسخة لأن Host/Join لم يُفعّلا بعد.

[تنزيل Artifact التطبيق](https://github.com/alwansan/BO/actions/runs/44913654405/artifacts/14710883570). فك ZIP وثبّت `black-room-ui-NO-GAMEPLAY-COOP.apk` منفصلاً عن النسخ السابقة. اختر ISO الموجودة لديك بالطريقة المعتادة. التقاط سجل القراءة اختياري؛ يمكنك اختيار Later لهذه التجربة.

1. في القائمة الرئيسية يفترض ظهور CO-OP مباشرة تحت الإعدادات وفوق خروج. إذا ظهرت قائمة ملف اللاعب، يكون قبل ملف اللاعب وتتحرك بقية الصفوف للأسفل.
2. اختر CO-OP: يفترض أن يفتح صفحة CO-OP / ROOM مباشرة، وفيها Host Room وJoin Room بحالة NOT AVAILABLE؛ هذا مقصود في هذه الدفعة ولا يعني اتصالاً فعلياً.
3. اضغط رجوع: يفترض أن تعود إلى نفس القائمة الرئيسية، ثم افحص أن الإعدادات المعتادة وزر بدء/متابعة المهمة ما زالت تعمل.

المطلوب نتيجة موضع الزر والدخول والرجوع فقط. لا إعادة لاختبارات Probe4 أو رفع ISO/Android data. إن لم يظهر الزر أو أخطأ الرجوع، صورة للقائمة واسم التطبيق الظاهر تساعد على تحديد الخلل.

الحالة الحالية لا تتضمن أجسام لاعبين متصلين أو مزامنة القصة. خطة الربط الفعلي في `docs/COOP_INTEGRATION_ROADMAP_AR.md`.
