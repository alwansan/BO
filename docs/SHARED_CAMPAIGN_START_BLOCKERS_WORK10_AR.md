## أقرب خطوة مأذونة ومعيار إنهائها

الأولوية الآن وصلة المحرك، وليست إضافة نقل أو TTL آخر. أول تسليم تكاملي يجب أن يحدد provider مرئيًا موثقًا على حد الرسم القائم: مجسم بسيط مملوك للمود، تحويل كاميرا/عمق وحفظ/استعادة render state، دورة إنشاء/إزالة مرتبطة بالتذكرة والمشهد، دون استعارة actor/NPC أو AI. التحقق المطلوب مصدر/ترجمة ضد SDK المصرح به وإثبات واجهة الكاميرا والرسم، لا تفعيل ABI غير مثبت. عند غياب هذه الواجهة يبقى الدمج الحي محجوبًا؛ لا نسمي وجود hook وحده إثباتًا.

وصلة التفاعل التالية تتطلب callback أصليًا موثقًا: مدخل ضيف موثوق -> فعل واحد على المضيف -> هوية كائن مستقرة وحالته الأصلية -> تطبيق/قراءة مقابلة على الضيف. لا نمرر ضغطة زر إلى أهداف وهمية أو نستخدم checkpoint restore بدل الحالة الحية. مرجع checkpoint المفتوح الذي روجع يحفظ backup ويترك live objectives للاستعادة الأصلية، فلا يسد هذه الوصلة.

بعد إثبات الوصلتين، يُختبر مسار واحد كامل من Start إلى الحركة المتبادلة والتفاعل وانتقال المرحلة؛ ثم حزمة قبول واحدة بهاتفين فقط. مسار ISO/APK اليدوي المقيد لن يُشغل. لا يوجد في هذه الدفعة APK أو co-op حي قابل للقبول.
