# الربط الفعلي للغرفة والأجسام والقصة — جلسة28

طلب المالك واضح: CO-OP تحت الإعدادات، ثم Host/Join، مضيف هاتف يختار المهمة، حتى4بشر بأجسام مستقلة، دخول متأخر وانتقال للمهمة التالية مع المضيف. الاختبارات السابقة كلها فردية. NPCالأعداء والأصدقاء ليسوا لاعبين متصلين،والرصدالمستقرلايعداختباراًعلىهاتفين.

## حدود APK وISO
APKهنايحتويالمحركالمعادترجمته،والشبكةوhooksوواجهةFlashالديناميكية. ISOمصدرالمحتوىوالـXBEالمطابق. زرالقائمةالجديدنُفذمنAPKعلىنفسISO؛إعادةتجميعISOلاتضيفشبكةأوشخصيةثانيةبذاتها. إذااحتجناتعديلmovie/rig/animationأوبياناتمرحلة،نستعملفرعاًتجريبياًجديداًفيbisoونسخةعملونربطالنسخةالمطلوبةببياناتتوافقصريحة. تعديلdefault.xbeيتطلبإعادةترجمةالصورةالجديدةوالتحققمنبصمتها،ولاbypassللبوابة.
