# نطاق المستخدم الكامل وبراهين القبول

يبقى الهدف مود قصة تعاوني فعلي لـBLACK Android؛ مختبر شبكة أو قائمة غرف أو نجاح إعادة الترجمة لا يكفي. جميع عناصر gameplay التالية غير منفذة/غير مثبتة حالياً.

| المطلب | الدليل المطلوب قبل القبول |
|---|---|
| هاتف هوست ولاعب ضيف ثم4 لاعبين | شخصيات مستقلة مرئية في المهمة نفسها على جهازين ثم4 أجهزة، مع حركة وكاميرا وسلاح مستقلين |
| Multiplayer: إنشاء/انضمام واسم الغرفة واللاعب واختيار المهمة | تجربة واجهة فعلية تنشئ غرفة وتدخل مهمة دون تغيير طور الفردي |
| اكتشاف LAN تلقائي واتصال يدوي عند غيابه | هاتفان على Wi-Fi، اكتشاف فعلي ثم اختبار تعطيل الاكتشاف والاتصال بـIP يدوياً |
| ZeroTier ثم Tailscale/WAN | أجهزة على شبكتين مختلفتين مع سجلات endpoint واتصال؛ لا مساواة loopback باختبار VPN |
| الانضمام أثناء المهمة | وصول الضيف إلى checkpoint/state الحالي وظهوره في موضع صالح قرب الفريق أو نقطة spawn مثبتة |
| AI والضرر والقتال والأهداف المشتركة | المضيف يقرر الأعداء والإصابات والأبواب والتدمير والذخيرة والأهداف؛ لا اختلاف للمهمة بين الأجهزة |
| نوك بدلاً من خسارة الفريق مباشرة | عداد60 ثانية مقترح من تفضيل المستخدم، مع بقاء مشهد اللعب مرئياً؛ انتهاء عداد لاعب لا ينهي مهمة الباقين |
| إنعاش الصديق | تفاعل زائد/علاج لمدة5 ثوان قرب اللاعب، والتحقق من انقطاع العلاج/المسافة/موت المعالج |
| الأعداء تتجاهل اللاعب المنكوب | اختيار أهداف AI يستثني المنكوب ويعيد إدراجه بعد الإنعاش |
| friendly fire بإعداد الهوست | اختبار إصابة صديق عند تشغيله وعدم إصابته عند إيقافه |
| مجسم اللاعب واسم فوقه | التحقق من وجود full-body model أولاً أو بديل ملائم، ثم مزامنة الاسم والموضع؛ الأذرع والسلاح لا تكفي |
| تقدم القصة والحفظ | مهمة كاملة ثم بقية المهام وcheckpoints؛ حفظ co-op معزول عن الفردي |
| استقرار الشبكة وسلامة game thread | فقد/تكرار/ترتيب الحزم وإعادة الاتصال، نقل مصادق ومحدود الذاكرة؛ لا كتابة ذاكرة لعبة من network thread |
| بناء Android واستعادة الجلسة | CI على الفرع التجريبي فقط، APK بعد بوابات الهوية/الأساس، وتوثيق النتائج والقيود وملفات الاستعادة |

تعطل مسار الأصل بسبب عدم توفر ملفه لا يثبت استحالة مسار المرشح الموجود. لكنه لا يجيز افتراض صحة ABI/offsets أو تجاوز hash gate. المصدر/SDK المرجعيان للقراءة فقط، وأصول اللعبة والحفظ والتوقيع الأصلي محفوظة.
