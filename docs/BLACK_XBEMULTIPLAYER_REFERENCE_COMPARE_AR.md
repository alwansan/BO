# BLACK-XBEMultiplayer as a reference for BLACK Android campaign co-op

Inspected Peterson047/BLACK-XBEMultiplayer main README.md and tools/extract_mp_map.py on 2026-11-23. Published package is Windows binary-only alpha Team Deathmatch with max 8 players, LAN and direct-IP lobbies, dedicated server, remote footstep sounds, hit feedback, and own multiplayer-only map packaging. It does not add a fully shared original BLACK campaign with its original enemies, scripted doors, save checkpoints and objectives. The linked source Peterson047/BLACK-Coop feat/windows-multiplayer returned 404 and was NOT inspected.

Its README and THIRD-PARTY-NOTICES list assets/anim/body.bca (3rd-party body animations by Kevin Iglesias), licensed for use within that mod only, with no extraction or redistribution. Do not copy this asset or compiled Windows BLACK.exe to BO. Only general architecture patterns like separate network thread, remote body animation, and host combat authority may be used.

The script tools/extract_mp_map.py operates on a user-provided original Black.iso to package a standalone level_mp00, including original level_00 geometry, collision files, destruct files, Stage 0001 NPC meshes and weapon metadata. This is for TDM and cannot be used to claim original campaign co-op.

Better accessible actual source: portingpete/Black-2006-Recomp, pinned b2512fafd3, src/recomp_manual.c. black_puppet_make clones original soldier appearance into a vacant 32-character slot and preserves original slot list/motion/weapon/parts ownership; black_puppet_follow plays original TM_AR_S_001/TM_AR_S_MOV and poses its model. Its experimental P2 splitscreen path swaps a 0x900 original actor and owned camera/weapon/physics context, and lacks robust full multiplayer original AI targeting. Do not blindly transplant PC split-screen into Android TLS. See docs/ORIGINAL_HOST_PLAYER_CONTEXT_ABI_AR.md.
