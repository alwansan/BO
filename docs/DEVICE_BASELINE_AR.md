# تجربة تشخيص النسخة الموجودة — ليست APK جماعية

نحتاج معرفة ما يشغله المحرك فعلياً على هاتف المالك قبل اختيار baseline أو تعديل gameplay. لا يتوفر XBE الأصلي82d058... عند المالك؛ الموجود c5bfed... نجح في التحليل الساكن فقط.

1. افتح نسختك العربية المثبتة حالياً، وادخل أول مهمة متاحة.
2. جرّب المشي والتصويب وإطلاق النار لمدة دقيقة تقريباً. أخبرنا هل نجحت أو أين توقفت، وهل ظهرت رسالة عن إصدار لعبة مختلف.
3. اخرج بالطريقة العادية وأرسل أحدث ملف `.log` إن أمكن من:
   `/storage/emulated/0/Android/data/com.racas.black.arabic/files/logs/`
   قد يكون `black.log` أو `black_XXX.log`. هذا مسار متوقع من package المحلية ومصدر v1.5.0، وليس تأكيداً لمسار النسخة المعدلة على هاتفك. إذا تعذر الوصول، يكفي أولاً جواب نتيجة المهمة ونوع الهاتف وإصدار Android؛ لا تعمل root أو تمسح بيانات اللعبة.

السجل المطلوب محلي في المحادثة، وليس commit على المستودع العام. يوضح build/device/GPU/path وسطر `Game: default.xbe ... sha1 ...`. لا ترسل ملفات حفظك أو مفاتيح توقيع أو ISO/XBE عاماً. لا تثبت APK جديدة لهذه التجربة.

نجاح النسخة الأصلية لا يثبت نجاح إعادة بناء المرشح أو لاعب ثان؛ هو دليل تشخيص يحدد مسار المتابعة.
