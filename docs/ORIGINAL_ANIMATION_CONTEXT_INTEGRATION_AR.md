# سياق حركة السلاح المستقل للاعب الأصلي الإضافي

Session102، 2026-11-23. التنفيذ في `coop/room_network/room_original_animation_context.hpp` مقتبس مع MIT attribution من مرجع PC المثبت b2512fafd3، ويبادل ذاكرة الحركة الفعلية عبر IO، وليس بوابة جاهزية أو لاعباً وهمياً. لا يوجد ربط تلقائي بالمحرك حالياً.

## ما ينفذه فعلاً

- يأخذ snapshot لورشة الحركة الأصلية2C3260..2CE710، مجموعة viewmodel والـslots، مصفوفات الأجزاء وcontrollers، وكتل animation pool ومؤشرات tops.
- يلتقط cache فارغاً **بعد** constructor950F0 الأصلي؛ لا يصنع cache صفرياً من تخمين. يمحو مؤشرات playing المستعارة في النسخة الخاملة فقط، حتى لا يحرر setup اللاعب الثاني حركة اللاعب الأول.
- يتحقق من هويات المشهد والتخصيصات والمؤشرات والحدود قبل أول كتابة؛ يبادل كتل FP المختارة فقط، ويرفض كتلة مشتركة مع NPC. يستعيد حالة اللاعب الأول ويحفظ تغييرات الثاني عند التبادل المعاكس.
- regression يفحص التبادل الفعلي، استمرار تغييرات اللاعب الثاني، بقاء كتلة NPC دون تبديل، رفض reuse وتبدل المؤشرات والمشهد والخيط، malformed tops وعدم وجود كتابة عند فشل preflight. روجعت تداخلات كامل set بما فيه prefix الذي لا ينسخه السياق، لا suffix فقط.

## شروط الربط التي لا يجوز اختصارها

`IO::Map` ليس مجرد `mem::IsCommitted`. يجب أن يثبت أن المنطقة المقصودة هي تخصيص/arena الحركة الأصلي الصحيح، مع طولها وعمرها ومصدرها. `Generation` يجب أن يتغير عند تدمير وإعادة استعمال النطاق **ولو بنفس العنوان**؛ عدّاد حزم الشبكة أو بقاء الصفحة committed لا يثبت ذلك. الـworkspace الثابت يحتاج witness خاصاً لا يخوّل بقية بيانات الصورة بالكتابة.

يلزم hook حقيقي بعد950F0 لحفظ cache المنشأ، وتوقيف/إثبات عدم وجود قارئ أو callback متزامن للحركة أثناء التبادل. صورة c5 الأصلية لها base10000 وimageSize577A40؛ استبعاد كلمة root معروفة وحدها لا يثبت أن كل عنوان آخر allocation صالح. لا تضف kernel shim يزعم provenance من committed pages.

يجب أن يجمع transaction الخارجي **كل** actor/camera/animation/weapon/audio/FX والروابط الأصلية قبل استدعاء setup أو tick. هذا السياق لا يبدل singleton الكاميرا أو actor أو بنوك الصوت. فقدان lifetime أثناء وجود اللاعب الثاني داخل core ليس حالة يمكن علاجها بكتابة عمياء: يجب اعتراض teardown الأصلي قبل تحرير الموارد، أو تعطيل السياق دون لمس نطاق قد أعيد استعماله. لا تمكّن هذا helper وحده باعتباره طور co-op.
