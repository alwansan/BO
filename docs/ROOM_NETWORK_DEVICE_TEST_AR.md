# BO-COOP — اختبار نسخة غرفة الشبكة الحقيقية على هاتفين (مؤجل إلى نجاح APK)

**ليس هذا اختبار طور القصة الجماعي.** الغرض اختبار الاتصال الموثق وقائمة البشر بين هاتف مضيف وعميل من داخل واجهة BLACK؛ لا شخصيات ثانية أو مزامنة مهام وقتال حتى الآن. لا يُنفذ قبل نجاح workflow `black-coop-room-network-apk.yml` وتحقق APK وتوقيعه.

## التحضير
- استعمل حزمة اختبار منفصلة باسم **BLACK Co-op NETWORK TEST** / `org.bocoop.black.roomnet`، وليس نسخة `roomui` المقبولة أو تطبيقك الأصلي. لا تحذف بيانات اللعبة الأصلية أو تبدل الحفظ.
- لا تنقل ISO/XBE أو ملفات الحفظ عبر GitHub أو طلبات الدعم. هذا APK لا يحتوي أصول اللعبة؛ استعمل ملفاتك القانونية المحلية كما في اختبار القائمة السابق.
- جهازان على شبكة LAN/Wi-Fi واحدة أو VPN/ZeroTier موثوق. الاتصال الحالي **TCP مباشر IPv4:port**، لا NAT traversal ولا relay ولا استضافة عامة.
- تفعيل المنفذ TCP **24872** على شبكة خاصة فقط؛ لا توجهه من الإنترنت العام. تأكد من اتصال الجهازين بالشبكة قبل البدء.

## الهاتف المضيف
1. افتح اللعبة حتى القائمة المقبولة، ثم **CO-OP**؛ في صفحة ROOM اختر **HOST ROOM**.
2. في شاشة Android اكتب اسمك واسم الغرفة، ثم PIN مكوّناً من **8 أرقام**، واترك المنفذ `24872` ما لم تستخدم منفذاً آخر.
3. اضغط **HOST — create secure room**. يجب ظهور `HOSTING`، عنوان IPv4 مناسب (ليس 127.0.0.1)، المنفذ، وبصمة الشهادة كاملة SHA-256 مكوّنة من 64 محرفاً سداسياً.
4. شارك عنوان `IPv4:24872` والبصمة عبر قناة تثق بها، وشارك PIN بشكل خاص. **تحقق من البصمة كاملة** على هاتف العميل؛ اسم الغرفة أو إعلان الشبكة ليسا إثبات هوية المضيف.

## الهاتف العميل
1. افتح نفس حزمة الاختبار ونسخة اللعبة المتوافقة، ثم **CO-OP → JOIN ROOM**.
2. اكتب اسم العميل، عنوان `IPv4:port` للمضيف، البصمة الكاملة، وPIN. اضغط **JOIN — verify host and PIN**.
3. يجب ظهور `JOINED` و**2/4 HUMANS** على المضيف والعميل. هذه أسماء/وصلات بشرية حقيقية عبر TLS؛ لا تعني وجود شخصين داخل العالم.
4. جرّب العودة من شاشة Android إلى Flash ثم الدخول إلى CO-OP من جديد. يجب حفظ الاتصال النشط وقائمة الأعضاء، وليس البدء تلقائياً بشخصيات افتراضية.

## اختبارات الفشل والأمان
- PIN خاطئ → رفض واضح، بلا انضمام في القائمة.
- بصمة مختلفة بمقدار محرف واحد → رفض TLS قبل JOIN.
- اختيار LEAVE → يختفي العضو من القائمة ويرجع العدد إلى 1/4 عند المضيف؛ لا يحتاج إعادة تشغيل اللعبة.
- إذا تغيرت الشبكة أو أُغلق التطبيق → يجب إغلاق الاتصال دون مساس بالحفظ.
- الاتصال الخامس بعد 4 بشر (المضيف وثلاثة عملاء) → `Room is full`.
- لا تضع PIN أو أي بيانات حساب أو ملفات حفظ أو أصول اللعبة في logs أو screenshots العامة.

## أدلة القبول
صور واضحة لعدد الأعضاء وحالات HOSTING/JOINED (يمكن إخفاء PIN)، معلومات عن إصدار Android ونتائج اختبارات الرفض/الرجوع، وأي crash log **منزوع البيانات الخاصة**. يجب التحقق من واجهة Flash والاتصال على أجهزة حقيقية قبل وضع علامة PASS.
