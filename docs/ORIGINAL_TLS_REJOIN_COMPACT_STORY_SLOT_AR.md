# BLACK Co-op — إصلاح الربط بعد مغادرة اللاعب وإعادة انضمامه (الجلسة 68)

عند مغادرة أحد البشر غرفة TLS ثم دخوله مجدداً لا يُعاد استعمال رقم اتصاله القديم. قد يصبح رقم اتصاله 5 أو أكبر، لكن ترتيب الشخصيات في القصة دائماً المضيف 1 ثم الضيوف 2 و3 و4. المشكلة السابقة كانت تمرير رقم الاتصال المتغير إلى مدخلات الحركة والمجسمات، وترفض رسائل عالم المضيف بعد إعادة الاتصال.

هذا الإصلاح يفصل `peerId` الأصلي الموثوق به (هوية الشبكة، لا يُستعمل للمجسم) عن `playerSlot` (رقم اللاعب وفق ترتيب القائمة الحالية وتذكرة القصة). صار إطار عالم الضيف وحركة المضيف يستخدمان خانة القصة المضغوطة حصراً، مع فحص جميع المشاركين وتطابق التذكرة والعالم. تُرفض هوية مجهولة أو قائمة لا تبدأ بالمضيف.

أضيف اختبار TLS فعلي يغلق ضيفاً، ثم يعيد انضمامه برقم أكبر، ثم ينقل ضمن اختبار الشبكة فقط موقع المضيف وحركة الضيف بعد COMMIT اصطناعي. **ليس هذا إثبات تحميل قصة BLACK الأصلية ولا إنشاء مجسم لعبة**. المسار التالي: إثبات تشغيل المشهد الحقيقي وتفعيل جسم بوت واحد لكل إنسان آخر، مع إبقاء منظور اللعب المحلي طبيعياً.
