> **For agentic workers:** Use superpowers:executing-plans task by task; owner already requested continuous autonomous execution until device testing is needed.

**Goal:** Obtain real read-only NPC pool membership/serial/reset evidence on owner's Android before attempting a real remote body.
**Architecture:** Fixed-capacity snapshot reader on verified c5 owner image; four sparse containers with occupancy/identity checks. Later isolated Probe3 package samples from player hook, wraps successful reset, and exports bounded local logs. No network or guest calls beyond forwarding original wrappers.

**Spec:** docs/ACTOR_POOL_STATIC_CONTRACTS_AR.md and docs/OWNER_PROJECT_OBJECTIVE_AR.md.

## Global constraints
Write only experiment/black-coop remotely; preserve Probe2 and baseline. No guest writes, raw assets/logs in public artifacts, network or claims of spawn proof. Exact c5 SHA gate. Fixed bounds: pool32, stride3C0, headers79A0/79B0/79C0/79D0, capacity32/16/8/8, +4capacity/+8occupied/+Cdata. Snapshot output unchanged on failure.

## Review focus
Sparse holes must not hide a tail actor; unreadable/overflow pointers must reject without guest dereference; duplicate/wrong ownership must reject; changes during read must reject when detectable (no atomicity claim); failed reset must not advance epoch.
